## 1. Executive Summary

รายงานนี้จัดทำขึ้นจากการตรวจสอบข้อมูลหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน (สพฐ. พ.ศ. 2551 ปรับปรุง 2560) ที่มีอยู่ในระบบจริง (`lib/subjectStandardsData.ts`) เพื่อใช้เป็น **Single Source of Truth** สำหรับ Smart Plan V3 Curriculum Engine โดยยึดหลัก:
- ข้อมูลมาตรฐานการเรียนรู้และตัวชี้วัดต้องมาจาก Master Data เท่านั้น
- **ห้าม AI สร้างหรือแต่งตัวชี้วัดขึ้นเองโดยเด็ดขาด (AI Calls = 0)**
- มี Adapter Layer ครอบเพื่อเตรียมพร้อมสำหรับการเปลี่ยนผ่านแหล่งข้อมูลในอนาคต

## 4. Known Data Gaps & Observations

1. **มัธยมศึกษาตอนปลาย (ม.5 - ม.6) ในบางกลุ่มสาระ:**
   - ภาษาไทย และ สังคมศึกษาฯ มีข้อมูลระดับ ป.1 – ม.4 ในขณะที่ ม.5 – ม.6 ยังไม่มีข้อมูลชุดแยกรายปี
   - กลุ่มสาระ ศิลปะ, การงานอาชีพ, สุขศึกษาและพลศึกษา, และภาษาอังกฤษ บันทึกข้อมูลช่วงชั้น ม.ปลาย รวบเป็น `ม.4-6` (ตามธรรมชาติของโครงสร้างหลักสูตรแกนกลาง)
2. **การงานอาชีพ:**
   - ในชุดข้อมูลปัจจุบัน ตัวชี้วัดของการงานอาชีพทั้งหมด 54 ตัวชี้วัด กำหนดประเภทเป็น `final` (ยังไม่มีตัวชี้วัดระหว่างทางในชุดนี้)
3. **การจัดการกรณีไม่พบข้อมูล:**
   - ระบบ Curriculum Engine จะคืนค่า `[]` (Empty Array) สำหรับระดับชั้นที่ไม่มีข้อมูล พร้อมแจ้งเตือนฝั่ง UI โดยไม่ให้ AI ปรุงแต่งตัวชี้วัดขึ้นเอง

## 5. Architectural Strategy for V3.2

- **ไม่ทำการ Migrate ข้อมูลลง Database ใน Wave นี้:** เนื่องจากชุดข้อมูลขนาด 853 KB เป็น static reference ที่ทำงานได้อย่างมีประสิทธิภาพและรวดเร็วบน Memory
- **ใช้ Adapter Pattern (`CurriculumProvider` Interface):** เพื่อให้ UI และ API ติดต่อผ่าน Interface เดียวกัน หากในอนาคตมีการเพิ่มหลักสูตรใหม่ (เช่น หลักสูตรฐานสมรรถนะ CBE) จะสามารถสลับ Implementation ได้ทันทีโดยไม่กระทบ Frontend
