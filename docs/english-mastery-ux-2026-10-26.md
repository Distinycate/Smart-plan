# English Mastery self-study UX — 26 October 2026

The learner area at `/english` now presents Thai-first bilingual navigation and a responsive green/cream layout. Beginners can choose a topic, read one lesson at a time, practise and resume a saved response using the existing Smart Plan account.

## Changes

- Four primary destinations: learning path, practice, review and progress. Additional writing, speaking, mediation, interaction and assessment tools remain available in an expandable menu, with role-scoped administration links.
- Thai titles for all 96 units, Thai/English topic search, explained A1–C2 levels, and a remembered level preference. The start button targets an accessible unit; a returning learner can resume the latest active attempt.
- A lesson outline, previous/next controls, saved completion and progress bar. Authored headings, emphasis and tables render as safe React text. Vocabulary, grammar and practice sections expand when needed.
- Bilingual response controls, recording guidance, feedback status and empty/error states. Same-origin navigation waits for a pending response save; a save failure retains the current page and answer. Final submission still locks edits.
- Mobile navigation, 48px touch targets, visible keyboard focus, skip link, reduced-motion support and Thai/English language attributes. The host header wraps on small screens.
- Speaking capture supports up to five minutes at a requested 64 kbps, retaining the existing 3 MB upload limit, consent, private playback and owner deletion. Uploaded files are still validated by the server. Lesson listening recordings are not generated by this change.

Progress and attempts come from the existing authenticated API/database; only the selected level is remembered in browser storage. No streak, learning score or human review is invented. No database migration is needed for these UI changes.
