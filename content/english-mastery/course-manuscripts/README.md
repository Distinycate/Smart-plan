# English Mastery — ต้นฉบับหลักสูตร A1–C2

ครบ 96 หน่วย (ระดับละ 16 หน่วย): 6 หน่วยตัวอย่างเดิมและต้นฉบับใหม่ 90 หน่วย

- บทเรียน 389 บท
- แบบฝึกพร้อมเฉลยอ้างอิง 1950 ข้อ
- งานเขียน พูด สื่อสารข้ามภาษา และโต้ตอบออนไลน์ 384 งาน
- รายการคำศัพท์/วลี 2954 รายการ นับรวมการทบทวนข้ามหน่วย ไม่ใช่จำนวนคำไม่ซ้ำ

เนื้อหาใหม่เป็นต้นฉบับ AI-assisted ที่แต่งขึ้นสำหรับโครงการ สถานการณ์ บุคคล องค์กร และตัวเลขเป็นข้อมูลสมมติ แต่ละหน่วยใหม่มีบทอ่าน 2 ชิ้น สคริปต์ฟัง 2 ชิ้น เป้าหมายภาษา คำอธิบายไทย แบบฝึก 20 ข้อ งานใช้ภาษา 4 งาน รูบริก การทบทวน และแนวทางแก้ข้อผิดพลาด

## วิธีใช้และขอบเขต

1. เริ่มจากเป้าหมายและบทเรียนตามลำดับ แล้วทำแบบฝึกโดยไม่เปิดเฉลย
2. ชุดนี้เป็น **ฉบับผู้สอน/ผู้ตรวจ** ซึ่งมีเฉลย เว็บผู้เรียนแยกเฉลยออกจากโจทย์
3. แบบเติมคำตรวจคำหรือวลีที่กำหนด งานตอบอิสระต้องใช้ผู้ตรวจและยอมรับการถอดความที่ถูกต้อง
4. สคริปต์ฟังครบในต้นฉบับ แต่ไฟล์เสียงและการตรวจคุณภาพเสียงยังไม่เสร็จ ใช้ผู้สอน/คู่ฝึกอ่านให้ฟังได้ การอ่านสคริปต์ไม่ใช่หลักฐานวัดการฟังอิสระ
5. ทุกหน่วยยังเป็น PRE_HUMAN_CONTENT_COMPLETE รอผู้สอนตรวจภาษา ระดับ ความเป็นธรรม และความตรงของการวัด ไม่ใช่เนื้อหาที่ผ่านการรับรอง CEFR หรือข้อสอบมาตรฐานแล้ว
6. ใช้ในระบบทดสอบแยกเท่านั้น การนำเข้าไม่เผยแพร่และไม่แก้ระบบหลัก ยังไม่ปรับ UX/UI ในรอบเนื้อหานี้
